# 🎵 Spotify Backend (Mini)

A mini Spotify-inspired backend built with **Node.js**, **Express.js**, and **MongoDB**. It provides authentication, role-based access, music uploads, and album management for artists.

## Features

* JWT Authentication
* User & Artist Roles
* Secure Password Hashing
* Music Upload API
* Album Creation API
* ImageKit Integration
* MongoDB with Mongoose

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt
* Multer
* ImageKit

> 🚧 More features like playlists, search, update/delete APIs, and music streaming will be added in future updates.
